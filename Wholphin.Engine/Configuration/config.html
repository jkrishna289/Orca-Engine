Server-side intelligence engine for the Orca X app.

Features

Content-based "Because You Watched X" / "More Like This" rows.
Mixes a small share of novel, unfamiliar-genre picks into recommendations to avoid a filter bubble.
Lets the app request unavailable titles through the engine via Jellyseerr.
Blends not-yet-available (requestable) titles into the catalog.
Also pulls trending/popular titles straight from TMDB (needs a TMDB key). Genre names + artwork are resolved automatically.
A row of titles added (or whose episodes aired) since the user's last visit.
Upcoming episodes/releases for catalog titles, from the *arr calendar (or TMDB).
Themed rows (Mind Bending, Dark Thrillers, Feel Good, …) rotated daily.
Server pre-fetches + transcodes low-bitrate trailers for card-focus previews. Requires yt-dlp and ffmpeg installed on the server; dormant otherwise.
Groq generates a per movie/series content-warning card shown briefly at the start of playback. Needs a Groq API key (below); pre-generated in the background and cached.

Optional. A hosted LLM polishes the "For You" row (reorders + writes the row title and per-item "why"). The engine works fully without it; recommendations are always computed locally first. Only an anonymized taste summary + public title metadata are sent to Groq — never account identity.

Embeddings (similarity vectors)

How "More Like This" / "Because You Watched" content vectors are produced. Default is local TF-IDF (free, on-device). Cloud/local-neural options give stronger semantic similarity; the engine falls back to TF-IDF when the chosen provider is unconfigured or fails. (Groq has no embeddings API, so it isn't an option here — it powers the re-ranker above.) Only the keys for the selected provider are needed.

Path to an ONNX sentence-transformer model on the server. On-box inference isn't implemented yet, so selecting ONNX currently falls back to TF-IDF.
